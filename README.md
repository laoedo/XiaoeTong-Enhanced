# 小鹅通课程页面防刷新

一个简单的用户脚本，用于阻止小鹅通 PC 课程页面在切换浏览器标签后自动刷新。

## 安装

1. 安装 Tampermonkey 或 Violentmonkey。
2. 安装 [`小鹅通课程页面防刷新.user.js`](./小鹅通课程页面防刷新.user.js)。
3. 重新打开小鹅通 PC 课程页面。

Greasy Fork 发布后将在这里补充安装地址：`{{GREASYFORK_URL}}`

## 说明

- 仅在小鹅通 PC 课程详情页运行。
- 不收集数据，也不会发送额外的网络请求。
- 不绕过登录、付费或课程访问权限。
- 首次使用时请确认课程进度仍能正常保存。
